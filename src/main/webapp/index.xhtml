Welcome to NitteSync

NitteSync is the single place for campus events at Nitte. Students discover events and register for them, clubs publish events, and administrators approve what gets published.

Students

Browse the approved events, open an event to see the details and register with one click.

Clubs

Create an event, keep it as a draft, edit it, and submit it for approval when it is ready.

Administrators

Approve or reject submitted events and see every event and registration in one place.
